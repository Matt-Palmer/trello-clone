# Pokémon Chess

A single-file, phone-friendly chess game where the pieces are Pokémon:

| Piece  | Pokémon   | Capture animation |
|--------|-----------|-------------------|
| Pawn   | Pikachu   | Thunderbolt       |
| Knight | Alakazam  | Psychic           |
| Bishop | Scyther   | X-Scissor         |
| Rook   | Golem     | Rock Throw        |
| Queen  | Nidoqueen | Poison Sting      |
| King   | Nidoking  | Earthquake        |

Full chess rules (castling, en passant, promotion, check/checkmate/stalemate, 50-move draw),
a built-in CPU opponent, pass-and-play mode, undo, and auto-save.

Open `index.html` in a phone browser and use **Add to Home Screen**.

Personal fan project. Pokémon is © Nintendo / Creatures / GAME FREAK; the artwork here is
original simplified drawings, not official assets. Do not publish to an app store.
